Der Leitterm entscheidet

Für sehr große positive oder negative x bestimmt allein der Leitterm anx^n das Verhalten der Funktionswerte. Zwei Fragen genügen: Ist der Grad n gerade oder ungerade? Ist der Leitkoeffizient a_n positiv oder negativ?

a_n > 0a_n < 0
n geradevon links oben nach rechts oben
x → −∞: f(x) → +∞ · x → +∞: f(x) → +∞		von links unten nach rechts unten
x → −∞: f(x) → −∞ · x → +∞: f(x) → −∞
n ungeradevon links unten nach rechts oben
x → −∞: f(x) → −∞ · x → +∞: f(x) → +∞		von links oben nach rechts unten
x → −∞: f(x) → +∞ · x → +∞: f(x) → −∞
  • Absolutes Glied a_0: Schnittpunkt mit der y-Achse (0 | a_0). Bei einer Kostenfunktion sind das die Fixkosten.
  • Unsortierte Terme: Der Leitterm ist der Summand mit dem höchsten Exponenten, egal wo er steht.
  • Produkte: Für den Leitterm nur die höchsten x-Potenzen jeder Klammer und den Vorfaktor multiplizieren.

Zwei Darstellungen, eine Funktion

DarstellungallgemeinDas lesen Sie direkt ab
Polynomformf(x) = anx^n + … + a1x + a_0Grad, Leitkoeffizient, y-Achsenabschnitt (0 | a_0)
Linearfaktorformf(x) = a_n · (x − x_1) · (x − x_2) · …alle Nullstellen und den Leitkoeffizienten
  • Satz vom Nullprodukt: Ein Produkt ist null, wenn mindestens ein Faktor null ist.
  • Vorzeichen: (x + 3) = (x − (−3)), die Nullstelle ist also x = −3.

So sieht der Term ausWerkzeugStation

Ausklammern in vier Schritten

  1. Funktionsterm gleich null setzen.
  2. x oder die höchstmögliche Potenz von x ausklammern.
  3. Satz vom Nullprodukt: x = 0 oder Klammer = 0.
  4. Die Klammer lösen, bei Grad 2 mit der pq-Formel.

x^2 + px + q = 0  ⇒  x_1,2 = −p/2 ± √((p/2)^2 − q)

Niemals durch x teilen. Dabei geht die Nullstelle x = 0 verloren. Vor der pq-Formel immer durch den Faktor vor x^2 teilen.

Biquadratische Gleichungen

Gleichungen der Form ax^4 + bx^2 + c = 0 enthalten nur die Exponenten 4, 2 und 0. Mit einer Ersetzung werden sie quadratisch.

SchrittWas Sie tunallgemein
1 Substituierenx^2 durch z ersetzen, dann ist x^4 = z^2az^2 + bz + c = 0
2 Lösenquadratische Gleichung mit der pq-Formel lösenz_1 und z_2
3 Rücksubstituierenaus jedem z wieder x bestimmenx^2 = z ⇒ x = ±√z
  • z > 0: zwei Lösungen x = +√z und x = −√z
  • z = 0: eine Lösung x = 0
  • z < 0: keine Lösung

Kurz erklärt

Seitenblick: die Produktionsfunktion

Eine Produktionsfunktion ordnet dem Input r (zum Beispiel Arbeitsstunden) den Output x zu. Beim ertragsgesetzlichen Verlauf (Grad 3, a_3 < 0) steigt der Output erst immer stärker, dann schwächer bis zum Ertragsmaximum, danach sinkt er.

  • Ohne Input kein Output: x(0) = 0. Das absolute Glied fehlt, die Nullstellen finden Sie durch Ausklammern.
  • Ökonomisch sinnvoll ist nur der Bereich von r = 0 bis zum Ertragsmaximum.

Die Rahmenschweißerei

Gewinnzone und Gewinnmaximum

  1. Gewinnschwelle prüfen: In der Wertetabelle f(x) = E(x) und g(x) = K(x) eingeben. Wo beide Spalten gleich sind, ist G(x) = 0.
  2. Gewinnmaximum eingrenzen: f(x) = G(x), Start 0, Ende 11, Inkre 1. Suchen Sie den größten Wert.
  3. Verfeinern: Um diese Stelle herum neu rechnen, zum Beispiel Start 5, Ende 8, Inkre 0,5.
  4. Preis dazu: Die gefundene Menge in p(x) einsetzen.
